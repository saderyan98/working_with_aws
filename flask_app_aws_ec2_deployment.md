
# Deploying a Flask Web Application on AWS EC2

## Overview

This guide explains how to create a simple Python Flask web application, deploy it to an AWS EC2 Ubuntu instance and access it through a web browser.
Flask is a lightweight Python framework used to build web applications.

## Prerequisites

- AWS account
- Running AWS EC2 Ubuntu instance
- SSH private key (`.pem` file)
- EC2 Public IPv4 address
- Python 3 and pip
- Internet connection

## Step 1: Connect to AWS EC2

Open terminal and connect to your EC2 instance:

```bash
ssh -i ~/.ssh/Datastudents.pem ubuntu@YOUR_PUBLIC_DNS
```

Replace `YOUR_PUBLIC_DNS` with your EC2 instance's Public IPv4 DNS address.

## Step 2: Install Python and Flask

Update the package list:

```bash
sudo apt-get update
```

Install Python, pip and virtual environment support:

```bash
sudo apt-get install -y python3 python3-pip python3-venv
```

**sudo = Superuser Do**
- It gives you administrator (root) privileges.

**apt-get = Package management tool**
- It downloads, installs, updates & removes software packages.

Create a directory for the Flask application:

```bash
mkdir flask_app
cd flask_app
```

Create a virtual environment:

```bash
python3 -m venv .venv
```

Activate virtual environment:

```bash
source .venv/bin/activate
```

Install Flask:

```bash
python -m pip install flask
```

## Step 3: Create the Flask Application

Create a Python file:

```bash
nano app.py
```
**`nano` is a text editor used inside the Linux terminal.**
**It allows you to create and edit files without needing an IDE.**

Add the following code:

```python
from flask import Flask

app = Flask(name)

@app.route('/')
def hello_world():
return 'Hello World'

if name == 'main':
app.run(host="0.0.0.0", port=5000)
```

### Code Explanation

- Flask is imported from the flask module.
- Flask(name) creates the Flask application object.
- @app.route('/') maps the root URL to the hello_world() function.
- hello_world() returns the message displayed in the browser.
- app.run() starts the Flask development server.
- if name == 'main': block ensures the application runs when app.py is executed directly.
- `host="0.0.0.0"` allows connections from outside the EC2 instance.
- `port=5000` specifies the port used by the application.

Save the file:

- Press `Ctrl + O`, then Enter to write to file.
- Press `Ctrl + X` to exit.

## Step 4: Configure the AWS Security Group

AWS security groups control incoming network traffic to the EC2 instance.

1. Open the AWS Management Console.
2. Navigate to **EC2 → Instances**.
3. Select your EC2 instance.
4. Open the **Security** tab.
5. Click the associated security group.
6. Select **Edit inbound rules**.
7. Add a new rule:

| Setting | Value |
|---------|-------|
| Type | Custom TCP |
| Port | 5000 |
| Source | My IP (for initial testing) |

8. Save the changes.

**Note:** Using `My IP` restricts access to your current public IP address. To access the app from another location, that location must also be allowed.
## Step 5: Run the Flask Application

Make sure you are inside the `flask_app` directory and your virtual environment is activated.

Run:

```bash
python app.py
```

Expected output:

```text
 * Running on all addresses (0.0.0.0)
 * Running on http://127.0.0.1:5000
 * Running on http://PRIVATE_EC2_IP:5000
```

The Flask application is now running on your EC2 instance.

Keep the terminal open while testing.

## Step 6: Access the Web Application

In the AWS EC2 Console, copy your instance's **Public IPv4 address**.

Open a web browser on your computer and enter:

```text
http://YOUR_PUBLIC_IP:5000
```

Replace `YOUR_PUBLIC_IP` with your actual EC2 Public IPv4 address.

You should see:

```text
Hello from AWS EC2!

My first Flask web application.
```

This confirms that the Flask application is accessible through your browser.

## Step 7: Test the Application

Check that:

1. The EC2 instance is running.
2. Flask is running without errors.
3. The security group allows inbound TCP traffic on port 5000 from your IP.
4. The webpage loads successfully.
5. The expected message appears.

You can also test the application from the EC2 terminal:

```bash
curl http://##.###.##.###:5000
```

This should return the HTML generated by the Flask application.

## Step 8: Stop the Application

Return to the terminal running Flask.

Press:

```text
Ctrl + C
```

This stops the Flask development server.

To run the application again:

```bash
cd ~/flask_app
source .venv/bin/activate
python app.py
```

## Troubleshooting

| Problem | Solution |
|---------|----------|
| SSH connection timed out | Check EC2 is running and port 22 is accessible |
| Permission denied (publickey) | Check the SSH key and run `chmod 400 ~/.ssh/Datastudents.pem` |
| Flask module not found | Activate the virtual environment and install Flask |
| Website not loading | Check EC2 Public IPv4 address and security group rules |
| Connection refused | Check Flask is running and listening on port 5000 |
| Address already in use | Stop the existing process or use another port |
| Website stops after closing terminal | Flask stops when its foreground process ends |
